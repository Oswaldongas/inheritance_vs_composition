# Employee Compensation: Inheritance vs Composition

Java implementation of the employee compensation example using two designs.

## Structure
- `inheritance/` – inheritance-based version
- `composition/` – composition-based version
- `uml/` – UML class diagrams (PlantUML sources and PNG exports)

## How to run
Requires JDK 17+. From the repository root:

```bash
# Inheritance version
javac inheritance/*.java
java inheritance.Main

# Composition version
javac composition/*.java
java composition.Main
```

Both versions produce the same payments.
